# Android (v1.0.2 test APK)

Нативное приложение на Android (Java) с движком скачивания Python (`yandex-music` через Chaquopy).

- **Android 8.0+**, CPU **arm64-v8a**. Для старых 32-битных телефонов APK не подходит.
- Треки, альбомы и плейлисты по ссылке `music.yandex.*`.
- Вход через Яндекс по одноразовому коду (Device Flow) или собственному OAuth-токену. Пароль не вводится. Токен не сохраняется в файлы, журнал или настройки.
- Выбор папки через системный Android Storage Access Framework; не требует доступа ко всему хранилищу.
- Качество MP3 (высокое / обычное), прогресс по трекам и по байтам, отмена.
- Можно отправить ссылку из другого приложения через меню **Поделиться** → Yandex Downloader.

## Установка

В GitHub Release `v1.0.2` скачайте `YandexDownloader-Android-v1.0.2.apk`, разрешите браузеру установку APK и установите приложение. Это **отладочная подписанная Android SDK сборка** для тестирования, не версия Google Play.

## Важно

Доступ к аудио требует прав аккаунта и определяется сервисом. Нет гарантии, что API отдаст MP3 в вашем регионе. Треки, передаваемые зашифрованным способом `encraw`, могут требовать криптографический модуль, который **не входит в первую Android тестовую сборку**. Это ограничение проявится как ошибка конкретного трека, без обхода DRM. Тесты компиляции APK **не подтверждают** успешного скачивания музыки.

Приложение скачивает во временный каталог приложения и переносит готовый файл в папку, выбранную пользователем; временные файлы удаляются. Если Android закроет приложение во время длительного скачивания, процесс остановится. Фоновый сервис для продолжения скачивания вне приложения в данной версии отсутствует.

## Сборка

GitHub Actions: **Build Android APK**. Для ручной сборки: JDK 17, Android SDK API 35, Python 3.11, Gradle 8.11.1.

```bash
cd android
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
