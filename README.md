# Yandex Downloader

Настольное приложение для Windows 10/11 и Linux (в том числе **Omarchy / Arch Linux**): загрузка доступных вашему аккаунту треков, альбомов и плейлистов по ссылке из Яндекс Музыки.

> **Важно:** это неофициальный клиент на базе [yandex-music-api](https://github.com/MarshalX/yandex-music-api). Это **не** функция экспорта, предоставляемая Яндексом. Условия сервиса и права на контент могут ограничивать скачивание. Необходимо пользоваться только теми записями, которые вы вправе сохранять. Приложение не обходит оплату, проверки авторизации и ограничения вашего аккаунта. При изменениях API функция может перестать работать.

## Возможности

- Ссылки на треки (`/album/123/track/456`, `/track/456`), альбомы и плейлисты (`/users/<login>/playlists/<id>`, `/playlists/<uid>:<kind>`, UUID).
- Вход по одноразовому коду на странице Яндекса (OAuth Device Flow); ручной ввод собственного OAuth-токена как запасной вариант.
- Выбор папки, автоматическая подпапка для плейлиста, безопасные имена файлов с ID трека.
- Качество **обычное / высокое MP3**, **lossless при наличии соответствующих прав**; реальный формат определяет ответ сервиса.
- Прогресс плейлиста, текущий трек, скорость, переданные байты и примерное время при потоковой передаче с известным размером. Для зашифрованного способа доставки библиотека не отдаёт покомпонентный прогресс: программа не изображает несуществующую скорость.
- Отмена, пропуск существующих файлов, очистка неполных `.part`, журнал ошибок. Не сохраняет токены на диск.

## Готовые бинарники (после запуска GitHub Actions)

В разделе **Actions → Build Windows and Linux** появляются два артефакта:
- `YandexDownloader-Windows-x64` — `YandexDownloader.exe` (самостоятельный исполняемый файл, без Python).
- `yandex-downloader-Omarchy-Linux-x64` — `yandex-downloader-linux-omarchy-x86_64.tar.gz` (содержит папку с исполняемым файлом и библиотеками).

**GitHub Release v1.0.1** создаётся автоматически после успешной сборки при первой отправке кода в ветку `main`. Файлы прикрепятся к релизу при условии, что GitHub Actions разрешён в репозитории. В Linux-архиве после распаковки запустите `./install-omarchy-binary.sh`, чтобы добавить приложение в меню Omarchy (или вручную запускайте `./yandex-downloader/yandex-downloader`).

**Замечание:** сборки исполняемых файлов должны производиться в соответствующей ОС; Windows `.exe` нельзя проверить в Linux. Проверка работоспособности также требует вашего аккаунта Яндекса. В Omarchy Linux бинарник может потребовать системные X11-библиотеки (обычно доступны через XWayland).

## Запуск из исходников

Требуется Python 3.12+ и интернет для первой установки зависимостей.

### Windows

Распакуйте проект и запустите `run-windows.bat`. Скрипт создаст окружение `.venv`, установит библиотеки и откроет приложение. Или установите зависимости вручную командой `py -3 -m pip install -r requirements.txt` и выполните `py -3 app.py`.

### Omarchy (Arch Linux)

```bash
sudo pacman -S --needed python python-pip tk
chmod +x run-omarchy.sh install-omarchy.sh
./run-omarchy.sh
```

Для создания пункта меню приложений Omarchy:

```bash
./install-omarchy.sh
```

Затем запустите **Yandex Downloader** из меню `Super+Space`. Скрипты работают с файлами в директории проекта и устанавливают зависимости в `.venv`, без изменения системных Python-пакетов.

### Собрать вручную

```bash
python -m pip install -r requirements-build.txt
python -m pytest tests/ -q
# Linux:
python -m PyInstaller --clean --noconfirm --onedir --windowed --name yandex-downloader --collect-all customtkinter app.py
```

В Windows используйте `--onefile --windowed --icon assets/icon.ico --name YandexDownloader` и получите `dist/YandexDownloader.exe`. Эти шаги автоматизированы в `.github/workflows/build.yml`.

## Авторизация

Нажмите **«Войти через Яндекс»**, откройте показанную страницу авторизации и введите код. Никакие пароли приложение не запрашивает и не сохраняет. Альтернативно можно вручную вставить *свой* OAuth-токен в скрытое поле; он остаётся только в памяти процесса. Если Device Flow недоступен для аккаунта, используйте только официально разрешённые способы получения токена.

После входа вставьте ссылку, выберите папку и качество, нажмите «Скачать».

## Ограничения

1. API неофициальный. Некоторые записи недоступны, качество может зависеть от подписки или региона. Наличие подписки не гарантирует предоставление экспорта файла.
2. Зашифрованные записи обрабатывает поддерживаемая библиотека `yandex-music[crypto]`; исходный код приложения не содержит собственного обхода DRM или логики извлечения ключей.
3. Точный размер и ETA определяются только при наличии Content-Length. Если сервер его не сообщает или библиотека не предоставляет прогресс, интерфейс отображает «—».
4. Для проверки настоящих загрузок необходим собственный авторизованный аккаунт. Автотесты покрывают URL, каталогизацию, атомарность, отмену и работу со структурой плейлиста, но не подтверждают доступность треков на живом сервере.

## Опубликовать на GitHub

Подключите GitHub CLI (`gh auth login`), затем в корне проекта выполните `./publish-to-github.sh` в Linux либо `./publish-to-github.ps1` в PowerShell. Эти скрипты создадут репозиторий `<ваш-логин>/yandex-downloader` и отправят исходники. При доступности GitHub Actions автоматически выполнятся сборки и публикация двух файлов в GitHub Release `v1.0.1`. Перед запуском убедитесь, что аккаунту разрешено создавать публичные репозитории и использовать GitHub Actions.

## Android

В репозитории есть отдельное Android-приложение (`android/`). **Тестовый APK v1.0.2** публикуется автоматически сборкой **Build Android APK**. [Инструкции для Android](android/README.md). Поддерживаются Android 8.0+ на arm64, вход по одноразовому коду Яндекса / личному OAuth-токену, выбор папки через системный диалог, MP3-треки и плейлисты. Токены не сохраняются. В первой Android-версии нет поддержки зашифрованной доставки `encraw` (зависит от криптографии) и постоянной фоновой загрузки. Проверка сборки не подтверждает получение аудиофайлов с серверов Яндекса.
